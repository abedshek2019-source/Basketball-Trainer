# Basketball Training Tracker

**Pathway:** AP

**User:** Basketball players who want to track their training and improvement.

**Problem:** Basketball players may have trouble keeping track of their workouts, shooting practice, and progress over time.

**Features:**

* Add and record workouts
* Track basketball statistics and training results
* View progress over time

**Question:** How can I store and organize a player's training data in Java so the program can save and display progress effectively?
